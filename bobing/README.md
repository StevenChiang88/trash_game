# 我這一生如履薄冰

踩著薄冰走過結冰的湖。冰有厚有薄，踩了會裂、站太久會破，後面的冰還一直在融。「我這一生如履薄冰，你說我能走到對岸嗎？」

主角「薄冰哥」是白色的大圓頭、小耳朵、腮紅、w 形的嘴，穿黑色長大衣、立領、手插口袋；在岸上一臉嚴肅，一踩上冰眉毛就垮下來、眼眶含淚。兩個朋友一隻是白色、頭頂藍色、尖耳朵的貓，一隻是奶油色的長耳朵兔子、半瞇著眼斜眼看人，平常在對岸等，他掉下去的時候會湊過來說那一句。角色畫在 `drawHero`、`drawPal`、`drawPal2`。

## 怎麼玩

| 操作 | 手機 | 鍵盤 |
| --- | --- | --- |
| 往前走一格 | 點一下，或往上滑 | ↑／W／空白鍵 |
| 往左、往右走一格 | 往左、往右滑 | ←→／A D |
| 退一格 | 往下滑 | ↓／S |

一次滑動只走一格。湖有五格寬，從下面的岸走到上面的對岸；過了一座，後面還有一座。

## 冰的規則

每塊冰有厚度，看顏色和裂痕判斷：

| 樣子 | 厚度 | 踩上去之後 |
| --- | --- | --- |
| 白色 | 3 | 變 2，還很穩 |
| 淺藍 | 2 | 變 1，不要待太久 |
| 深藍、有裂痕 | 1（薄冰） | 變 0，只能踩過去，不能停 |

- **踩上去少 1。** 站著不動每 1.5 秒再少 1。
- **變成 0 之後還能撐 0.75 秒**，然後破掉變成洞。腳一離開，已經是 0 的冰馬上就破，所以路會斷在身後。
- **看得到的洞不會自己走進去**（會擋住，提示「那是水」）。
- **融冰線**（橘色那條）：一踏上湖面，後面的冰就從岸邊開始一排一排融掉、往上追。越後面的湖融得越快。**它一掃到你腳下那一排就直接掉下去**，不會再多撐一下。走到對岸就停。

之後的湖會多出這些東西：

| 第幾座起 | 東西 | 效果 |
| --- | --- | --- |
| 2 | 雪 | 蓋著雪的冰看不出底下多厚，踩上去才知道 |
| 2 | 朋友來亂 | **兔子丟雪球**：每 2.8～4.8 秒一波（越後面越密，最快六折），第 5 座起一次兩顆、第 9 座起三顆。瞄準你前面三排、左右一格以內的冰，先出現紅圈和影子，0.85 秒後砸下來，那格少兩級（淺藍和薄冰會直接破）。每波有四成機會其中一顆直接瞄準你腳下：不走開的話腳下的冰只剩 0.45 秒。不會瞄準水。**藍貓搶魚**：每 7～12 秒來一次，前面五排內有魚就跳過去守著，2.2 秒後吃掉（頭上有倒數的圈）；你先踩到就是你的。前面沒魚的時候牠才幫忙：把最近一格蓋著雪的冰掀開 |
| 4 | 滑冰（亮亮的、有斜線） | 踩上去停不住，一路往同一個方向滑到不滑的冰、岸邊或牆。前面是洞的話會滑進去 |
| 3 | 湖況 | 每座湖有 65% 的機會抽到下面其中一種，不連續重複 |

到對岸的時候會預告「下一座：○○」，走在那座湖上時畫面下方也會一直寫著。

| 湖況 | 效果 |
| --- | --- |
| 薄冰湖 | 薄冰的比例多三成（最多八成），幾乎一步都不能停 |
| 碎冰湖 | 洞多將近一倍（最多四成），路要繞 |
| 溜冰場 | 將近一半是滑冰 |
| 大雪 | 六成的冰蓋著雪，看不出厚薄 |
| 起霧 | 只看得清前面兩三排 |
| 回暖 | 融冰線快 45%，而且幾乎一踏上去就開始追 |
| 大風 | 每 2.4～3.8 秒一陣風：先出現箭頭預告 0.9 秒，然後把你往那邊推一格（被推到的冰一樣會少一級）。旁邊是洞就會被吹進去；靠著那一側的牆就推不動 |
| 魚群 | 魚從 2 條變 7 條，算是喘口氣 |

每座湖都保證至少有一條走得過去的路（那條路上不會放滑冰）。

## 分數

- **過了幾座湖**是主要紀錄。
- **膽量**：踩厚冰 +1、淺藍 +2、薄冰 +3。連續踩薄冰有加成（「如履薄冰 ×N」，每多一塊多 25%，最多 3 倍），踩到別的就歸零。
- **魚**：凍在冰裡，通常在比較薄、不在主要路線上的位置，踩上去 +10，而且會存起來（見下面「用魚換能力」）。
- 每到一個對岸：+10 × 第幾座。

掉下去就結束，從第一座重來。

## 用魚換能力

撈到的魚會一直存著（掉下去也不會不見），在封面和結算畫面可以拿來換東西，換到的東西下一局帶著走、用完就沒了：

| 能力 | 價錢 | 效果 |
| --- | --- | --- |
| 爬起來 | 8 條魚 | 掉下去的時候爬起來一次：腳下那格重新結成厚冰，融冰線退後幾排、停 1.2 秒。一局最多帶一次 |
| 跳兩格 | 5 條魚換三次 | 畫面右下角出現「跳」，按一下往前跳兩格、越過中間那格（鍵盤 J）。落點是洞的話不會跳、也不扣次數。一局最多帶六次 |
| 打車 | 20 條魚 | 畫面右下角出現「打車」，按一下，計程車從後面開過來接人，一路開到這座湖的對岸（人在岸上的話是下一座），那座湖照算（鍵盤 T）。坐車的 1.15 秒裡不能動、冰也不會融。同時會放「給你 20 塊打車吧」那句。一局最多帶一次 |

模擬的玩家一局大約撈 2～7 條魚，所以大概一兩局換得到跳、兩三局換得到爬起來、四到六局換得到打車。

| 過了幾座 | 封號 |
| --- | --- |
| 0 | 一腳就沒了 |
| 1 | 至少過了一座 |
| 2 | 有走到過對岸 |
| 4 | 薄冰哥本人 |
| 7 | 如履平地 |
| 12 | 對岸的常客 |
| 20 | 這不是薄冰哥，是冰上之神 |

## 湖怎麼變難

第 n 座湖：長度 7+n 排（最多 16），洞的比例 4%+3%×n（最多 26%），薄冰 10%+6%×n（最多 55%），融冰線每秒 0.8+0.13×n 排（最多 3 排），踏上湖面後 1.3−0.05×n 秒（最少 0.6 秒）開始追。湖況會在這個基礎上再加。

## 平衡

難度只用模擬的玩家跑過（各 30 次），還沒有真人試玩的數據。模擬的玩家看盤面不花時間，真人應該比同樣步調的模擬玩家差：

| 模擬的玩法 | 過幾座（中位數） | 一局多久 |
| --- | --- | --- |
| 很猶豫（0.7 秒一步，只看下一格） | 3 | 約 30 秒 |
| 普通步調（0.34 秒一步，看兩格） | 9 | 約 50 秒 |
| 很快（0.22 秒一步，看三格） | 13 | 約 50 秒 |
| 專挑薄冰和魚 | 9 | 約 40 秒 |

## 聲音

八個 `voice-*.mp3` 是遊戲裡的語音。不想要語音的話：刪掉這八個檔，把 `index.html` 裡 `CLIP_FILES` 的清單清空，遊戲會退回成開場用內建中文語音唸、其他時候沒有語音。其他音效（踩冰、裂開、落水）都是程式合成的。

什麼時候放：

- **封面**：第一次點畫面時放一次。
- **開場**：按開始之後的那句獨白。
- **走的時候**：開始 8～13 秒後冒出第一句，之後每隔 12～22 秒隨機一句（`CHAT_FIRST`、`CHAT_GAP`），不連續重複；前一句還沒講完會等。掉下去的瞬間正在講的那句會停。
- **結算**：掉下去之後，兩個朋友滑到他旁邊（0.85 秒）就開始放，不等結算卡片；兩句隨機挑一句。

要換成別的錄音：把同名的檔案蓋掉，或改 `CLIP_FILES` 裡的檔名；同一個時機可以放好幾個檔，會隨機挑。音量在 `CLIP_GAIN`。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 遊戲本體，單一檔案，沒有建置步驟；畫面用 canvas 畫，音效用 Web Audio 合成 |
| `voice-title.mp3` | 封面的那段話（約 4.4 秒）。瀏覽器要先有點擊才能出聲，所以是第一次點封面時放一次 |
| `voice-intro.mp3` | 開始走的時候那句獨白（約 3.2 秒） |
| `voice-play1.mp3`～`voice-play4.mp3` | 走的時候隨機穿插的四句。第二句是「是因為他喜歡吃薄餅嗎」，第三句是「今天還沒走到對岸啊？」，第四句是「給你 20 塊打車過去吧」；打車的時候放的也是第四句（`V_TAXI`） |
| `voice-over1.mp3`、`voice-over2.mp3` | 結算的兩句，隨機挑一句、不連續重複；第一句也會在走的時候穿插 |
| `og.png` | 貼到脆、LINE 時的預覽圖（1200×630） |
| `favicon.svg`、`apple-touch-icon.png` | 分頁圖示、加到主畫面的圖示 |

存在瀏覽器裡的資料：`bi.best`（最多過了幾座湖）、`bi.score`（最高膽量）、`bi.fish`（存了幾條魚）、`bi.kit`（下一局要帶的能力）、`bi.mute`（靜音）。

要調數值：

- 冰撐多久：檔案開頭的 `STAND`（站多久少一級）、`GRACE`（變 0 之後撐多久）、`LEAVE_T`（離開後多久破）。
- 每座湖的長度、洞、薄冰、雪、滑冰、融冰速度，以及各種湖況怎麼改這些數字：`lakeOf`；湖況的名字和說明：`KINDS`；第幾座開始有、機率多少：`KIND_FROM`、`KIND_P`；風多久一陣、預告多久：`GUST_GAP`、`GUST_WARN`。
- 怎麼排一座湖（含保證走得過去的那條路）：`genLake`。
- 兔子多久丟一波雪球、預告多久、砸掉幾級、瞄準腳下的機率、被砸中後撐多久、第幾座起兩顆／三顆：`BALL_GAP`、`BALL_WARN`、`BALL_DMG`、`BALL_ME`、`BALL_GRACE`、`BALL_2`、`BALL_3`；藍貓多久來一次、多久吃掉魚：`CAT_GAP`、`CAT_EAT`；第幾座開始：`PAL_FROM`。
- 能力的價錢、一次買到幾次、一局最多帶幾次：`KIT`；跳一次花多久：`JUMP_T`。
- 封號：`RANKS`；到對岸時講的話：`SHORE_LINES`。
