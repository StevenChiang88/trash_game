# 我的豆花30塊

提著一碗 30 塊的豆花過馬路。車要閃，手上那袋豆花也不能晃過頭。掉了就只能站在路中間大叫：「我的豆花，30 塊！」

向台灣那支老迷因致敬的小遊戲：2014 年網路上瘋傳的短片，兩個女學生過馬路，其中一個手上的豆花掉了，當場喊出「我的豆花，30 塊！」（[當時的報導](https://www.ettoday.net/news/20140510/355602.htm)）。非官方、與影片當事人無關；畫面全部是自己畫的卡通造型，角色不具名、不取真人長相，聲音也是程式合成的，沒有用原影片的任何素材。

## 怎麼玩

只有一個動作：**點一下（或按空白鍵／↑）往前走一步**。不能後退。

- **車**：每條車道各開各的，近的半邊從左邊來、遠的半邊從右邊來。站的那一線有車開到就被撞，豆花掉。
- **豆花會晃**：每走一步，袋子就被甩一下，畫面左上的「豆花晃動」條會漲。連踩太快會越晃越大，晃過頭就掉。停下來等一下它會自己慢慢靜下來。
- **被叭**：站在車道上、車快開到的時候會被叭，嚇一跳手一抖，袋子又多晃一下。
- **水窪**：踩到會滑，一樣多晃一下。前面有水窪時，先等袋子靜下來再踩。
- **人行道和分隔島**是安全的，可以站著等車流、等袋子靜下來。

每過一條馬路算保住 30 塊。紀錄是過了幾條馬路。

| 過了幾條 | 封號 |
| --- | --- |
| 0 | 剛買就掉了 |
| 1 | 至少過了一條 |
| 4 | 還算小心 |
| 9 | 過馬路有練過 |
| 16 | 穩得像端湯 |
| 26 | 斑馬線上的職人 |
| 40 | 豆花守護神 |

## 馬路怎麼變難

| 第幾條 | 車道 |
| --- | --- |
| 1–2 | 兩線，沒有分隔島 |
| 3–4 | 三線，中間有分隔島（一線＋兩線） |
| 5–7 | 四線，中間有分隔島（兩線＋兩線） |
| 8–10 | 五線（兩線＋三線），開始有要連過三線的路段 |
| 11 之後 | 六線（三線＋三線） |

每過一條，車速快一點、車距密一點；車距到第 15 條、車速到第 20 條封頂。靠人行道的那一線機車多、速度快；中間的車道有公車和貨車，車身長、擋比較久。第 2 條起有機會出現水窪。

手機螢幕上大概只看得到車子開到前一秒多，所以前面幾條最多只要連過兩線。

## 袋子的晃動

袋子是一個會自己慢慢靜下來的單擺（`W0` 擺動快慢、`ZETA` 靜下來的速度），每走一步固定往同一個方向推一下（`STEP_J`）。所以：

- 連點三下以上幾乎一定晃過頭。
- 袋子正往回盪的時候踏出去，會剛好抵銷，反而變穩。抓到這個節奏可以走得比別人快。

## 平衡

難度只用模擬的玩家跑過（各 40 場），還沒有真人試玩的數據：

| 模擬的玩法 | 過幾條（中位數） |
| --- | --- |
| 亂點、連按 | 1 |
| 只看下一線有沒有車 | 5 |
| 會把整段路看完、抓袋子節奏再走 | 11–20 |

一場大約十幾秒到一分鐘。
