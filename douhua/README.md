# 我的豆花30塊

提著一碗 30 塊的豆花過馬路。車要閃，手上那袋豆花也不能晃過頭。掉了就只能站在路中間大叫：「我的豆花，30 塊！」

向台灣那支老迷因致敬的小遊戲：2014 年網路上瘋傳的短片，兩個女學生過馬路，其中一個手上的豆花掉了，當場喊出「我的豆花，30 塊！」（[當時的報導](https://www.ettoday.net/news/20140510/355602.htm)）。非官方、與影片當事人無關；畫面全部是自己畫的卡通造型，角色不具名、不取真人長相，沒有用原影片的畫面或聲音。

## 怎麼玩

| 操作 | 手機 | 鍵盤 |
| --- | --- | --- |
| 往前走一步 | 點一下，或往上滑 | ↑／W／空白鍵 |
| 橫著走一格 | 往左、往右滑 | ←→／A D |
| 退一步 | 往下滑 | ↓／S |

斑馬線有三個直排可以站。已經過完的馬路不能再走回去。

- **車**：每條車道各開各的，近的半邊從左邊來、遠的半邊從右邊來。站的位置有車開到就被撞。橫著走可以多爭取一點時間，也可以退回上一線。
- **豆花會晃**：每走一步（不管哪個方向），袋子就被甩一下，畫面左上的「豆花晃動」條會漲。連走太快會越晃越大，晃過頭就掉。停下來等一下它會自己慢慢靜下來。
- **被叭**：站在車道上、車快開到的時候會被叭，嚇一跳手一抖，袋子又多晃一下。
- **水窪**：在某一個直排上，踩到會滑，一樣多晃一下。可以繞過去。
- **人行道和分隔島**是安全的，可以站著等車流、等袋子靜下來。站太久朋友會催。

紀錄是過了幾條馬路。

## 朋友和她那碗

朋友跟在後面，只站在安全的地方（人行道、分隔島），等你離開才跑過來。

- **她一開始也買了一碗。** 你的掉了（不管是晃掉還是被撞），喊完那一句，她會把她那碗給你：「拿去啦，你欠我 30！」，你退回她站的地方繼續走。
- 她手上也沒有的時候再掉，才真的結束。
- **零錢**：車道上有 5 塊、10 塊，偶爾有 50 塊，走到那一格就撿起來。
- **好險**：剛離開的位置馬上有車開過去，加 5 塊。
- **再買一碗**：每條馬路對面都有一攤豆花。朋友手上沒有、零錢又滿 30 塊的時候，走到對面她就會再買一碗（扣 30）。

## 那一句

豆花掉了會喊「我的豆花！30 塊！」。聲音是用手機／電腦內建的中文語音唸的（調高、調快），不是原影片的聲音。沒有中文語音的環境（部分 App 內建瀏覽器）就只有合成的尖叫聲。靜音鍵會一起關掉。

想換成自己錄的：把音檔放進這個資料夾，在 `index.html` 裡把 `VOICE_FILE` 設成檔名（例如 `'voice.mp3'`）就會改放那個檔。

## 馬路怎麼變難

| 第幾條 | 車道 |
| --- | --- |
| 1–2 | 兩線，沒有分隔島 |
| 3–4 | 三線，中間有分隔島（一線＋兩線） |
| 5–7 | 四線，中間有分隔島（兩線＋兩線） |
| 8–10 | 五線（兩線＋三線），開始有要連過三線的路段 |
| 11 之後 | 六線（三線＋三線） |

每過一條，車速快一點、車距密一點；車距到第 15 條、車速到第 20 條封頂。靠人行道的那一線機車多、速度快；中間的車道有公車和貨車，車身長、擋比較久。第 2 條起有機會出現水窪。

手機螢幕上大概只看得到車子開到前一秒多，所以前面幾條最多只要連過兩線。

## 袋子的晃動

袋子是一個會自己慢慢靜下來的單擺（`W0` 擺動快慢、`ZETA` 靜下來的速度）。往前走推一下、往後退反方向推一下、橫著走往那一邊推一下（力道小一點）。所以：

- 同一個方向連走三步以上幾乎一定晃過頭。
- 袋子正往回盪的時候踏出去，會剛好抵銷，反而變穩。抓到這個節奏可以走得比別人快。

## 平衡

難度只用模擬的玩家跑過（各 40 場），還沒有真人試玩的數據。模擬的玩家只會直直往前走，不會橫移、不會退、不會特地去撿零錢，而且只算到「第一次掉」為止（沒算朋友那一碗），所以真人應該比這些數字好：

| 模擬的玩法 | 第一次掉之前過幾條（中位數） |
| --- | --- |
| 亂點、連按 | 1–2 |
| 只看下一線有沒有車 | 5 |
| 會把整段路看完、抓袋子節奏再走 | 12–24 |
