# 我的豆花30塊

提著一碗 30 塊的豆花過馬路。車要閃，手上那袋豆花也不能晃過頭。掉了就只能站在路中間大叫：「我的豆花，30 塊！」

向台灣那支老迷因致敬的小遊戲：2014 年網路上瘋傳的短片，兩個女學生過馬路，其中一個手上的豆花掉了，當場喊出「我的豆花，30 塊！」（[當時的報導](https://www.ettoday.net/news/20140510/355602.htm)）。非官方、與影片當事人無關；畫面全部是自己畫的卡通造型，角色不具名、不取真人長相。豆花掉的時候喊的那一句（`voice.mp3`）是從原影片剪下來的幾秒聲音，除此之外沒有用原影片的素材。

## 怎麼玩

| 操作 | 手機 | 鍵盤 |
| --- | --- | --- |
| 往前走一步 | 點一下，或往上滑 | ↑／W／空白鍵 |
| 橫著移動 | 手指按著左右拖，拖多少她就移多少 | ←→／A D |
| 退一步 | 往下滑 | ↓／S |

一隻手指按著拖的時候，另一隻手指點一下也是往前走。一次上下滑只算一步。斑馬線的寬度內都可以站；已經過完的馬路不能再走回去。

- **車**：每條車道各開各的，近的半邊從左邊來、遠的半邊從右邊來。站的位置有車開到就被撞。橫著走可以多爭取一點時間，也可以退回上一線。
- **豆花會晃**：每走一步（往前或往後），袋子就被甩一下；橫著移動也會帶到一點。畫面左上的「豆花晃動」條會漲。連走太快會越晃越大，晃過頭就掉。停下來等一下它會自己慢慢靜下來。
- **被叭**：站在車道上、車快開到的時候會被叭，嚇一跳手一抖，袋子又多晃一下。
- **水窪**：在車道的左、中、右其中一處，踩到會滑，一樣多晃一下。可以繞過去。
- **人行道和分隔島**是安全的，可以站著等車流、等袋子靜下來。站太久朋友會催。

紀錄是過了幾條馬路。

## 朋友和她那碗

朋友貼在你左後方一起走，你走她就走、你橫移她也跟著。車只會撞到你，不會撞到她。

- **她一開始也買了一碗。** 你的掉了（不管是晃掉還是被撞），喊完那一句，她會把手上的一碗給你：「拿去啦，你欠我 30！」，兩個人退回最近的人行道或分隔島繼續走。
- 她手上也沒有的時候再掉，才真的結束。
- **零錢**：車道上有 5 塊、10 塊，偶爾有 50 塊，在左、中、右其中一處，碰到就撿起來。
- **好險**：剛離開的位置馬上有車開過去，加 5 塊。
- **多買幾碗**：每條馬路對面都有一攤豆花。走到對面時，零錢每滿 30 塊她就多買一碗（最多提 9 碗），左上角會顯示她手上有幾碗。

## 那一句

豆花掉了，先是一聲合成的尖叫，接著放 `voice.mp3`：從原影片剪下來的那一句。靜音鍵會一起關掉。

音檔載不到的時候（或把 `index.html` 裡的 `VOICE_FILE` 設成空字串），會改用手機／電腦內建的中文語音唸「我的豆花！30 塊！」（調高、調快）；連中文語音都沒有的環境就只有尖叫聲。

要換成別的錄音：把同名的檔案蓋掉，或改 `VOICE_FILE` 的檔名；音量在 `VOICE_GAIN`。之後如果要拿掉原音，刪掉 `voice.mp3`、把 `VOICE_FILE` 改成 `''` 就好，遊戲會自動退回內建語音。

## 馬路怎麼變難

| 第幾條 | 車道 |
| --- | --- |
| 1–2 | 兩線，沒有分隔島 |
| 3–4 | 三線，中間有分隔島（一線＋兩線） |
| 5–7 | 四線，中間有分隔島（兩線＋兩線） |
| 8–10 | 五線（兩線＋三線），開始有要連過三線的路段 |
| 11 之後 | 六線（三線＋三線） |

每過一條，車速快一點、車距密一點；車距到第 15 條、車速到第 20 條封頂。靠人行道的那一線機車多、速度快；中間的車道有公車和貨車，車身長、擋比較久。第 2 條起有機會出現水窪。

手機螢幕上大概只看得到車子開到前一秒多，所以前面幾條最多只要連過兩線。

## 袋子的晃動

袋子是一個會自己慢慢靜下來的單擺（`W0` 擺動快慢、`ZETA` 靜下來的速度）。往前走推一下、往後退反方向推一下，橫著移動則是移多少推多少（力道小很多）。所以：

- 連續往前走三步以上幾乎一定晃過頭。
- 袋子正往回盪的時候踏出去，會剛好抵銷，反而變穩。抓到這個節奏可以走得比別人快。

## 平衡

難度只用模擬的玩家跑過（各 40 場），還沒有真人試玩的數據。模擬的玩家只會直直往前走，不會橫移、不會退、不會特地去撿零錢，而且只算到「第一次掉」為止（沒算朋友那一碗），所以真人應該比這些數字好：

| 模擬的玩法 | 第一次掉之前過幾條（中位數） |
| --- | --- |
| 亂點、連按 | 1–2 |
| 只看下一線有沒有車 | 5 |
| 會把整段路看完、抓袋子節奏再走 | 12–24 |

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 遊戲本體，單一檔案，沒有建置步驟；畫面用 canvas 畫，音效用 Web Audio 合成 |
| `voice.mp3` | 豆花掉的時候喊的那一句（約 4 秒，原影片的聲音） |

要調數值：晃動在檔案開頭的 `W0`、`ZETA`、`STEP_J`、`HONK_J`、`PUD_J`、`LIMIT`；橫著移動的範圍、速度在 `XMIN`、`XMAX`、`LAT_V`、`LAT_J`；好險的判定和獎勵在 `NEAR_T`、`NEAR_V`；朋友最多提幾碗在 `MAX_SPARE`；馬路的車道配置、車速、車距、零錢和水窪在 `genStreet`；車種在 `KIND` 和 `mkVeh`；封號在 `RANKS`。
