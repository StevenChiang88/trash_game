# 絕命鈴師

阿伯不能說話，只能按鈴。姪子拿著步槍，用槍口在板子上一格一格地指；指到對的注音就按鈴，把阿伯想說的話一個字一個字拼出來。每三回合姪子會問一題跟這群人有關的事，板子換成人物牌，槍指到對的人就按。阿伯脾氣很差，想說的大多是罵人的話；姪子沒耐心，槍口會突然亂指。

向《絕命毒師》裡那位坐輪椅、靠按鈴溝通的阿伯致敬的同人小遊戲，非官方、與原作及其製作公司無關。畫面全部是自己畫的卡通造型，角色都不具名。

## 怎麼玩

- **按鈴**：整個畫面點哪裡都是按鈴；電腦按空白鍵或 Enter。
- 上面的卡片是阿伯想說的話，每個字右邊直排注音。**紅色**的那個注音是現在要拼的。
- 姪子的槍口在注音板上一格一格移動，指到那個注音時按鈴。聲調（ˊ ˇ ˋ ˙）也要拼，一聲不用。
- 按對：換下一個注音，整句拼完姪子會唸出來。
- 按錯：姪子會把那個注音聽成別的字（「貓？阿伯你要貓？！」），耐心扣一大截。
- 沒按到：槍口會再繞回來，只是多花時間。
- 小提示：槍口指到對的注音時，阿伯的眉毛會挑起來。

左上角是「姪子的耐心」：會一直慢慢掉，按對會補、過一回合補更多、按錯扣很多，掉光就結束。分數是撐了幾回合。

## 人物題

每三回合一題（第 3、6、9… 回合）。上面的卡片變成姪子的問題，例如「是誰殺了炸雞叔叔？」，板子換成六張人物牌，槍指到對的人時按鈴。有的題目有兩個人都算對。

人物都只有外號、沒有名字：戴帽子的、穿很寬的、花西裝的、炸雞叔叔、收礦石的、修門的、一身紫的、雙胞胎、紅襯衫手下、愛笑的姪子、我自己。題目目前 14 題，在 `QUIZ` 裡。

## 姪子會突然亂指

第 2 回合起，槍口每換一格都有機率突然亂來（機率隨回合增加，最高約三成），畫面上會跳出他喊的話：

| 喊什麼 | 會怎樣 |
| --- | --- |
| 掉頭！ | 改成反方向走 |
| 跳！ | 跳過一格 |
| 騙你的！ | 眼看就要指到答案，卻跳去別格 |
| 快快快！ | 接下來三格停留時間變短 |
| 洗牌！ | 第 7 回合起：板子上的牌全部換位置 |

不管怎麼亂，答案一定輪得到。

## 仇人來訪

每過 4 回合，戴眼鏡、西裝筆挺的仇人會坐到對面。5 秒內狂按鈴把怒氣條灌滿，就能把他氣走，姪子的耐心補滿；沒灌滿也不會扣分。

## 難度

| 第幾回合 | 句子 | 板子上幾個注音 |
| --- | --- | --- |
| 1 | 一個字（幹、滾、靠…） | 4 |
| 2–3 | 一到兩個字 | 6 |
| 4–6 | 兩到三個字（靠北、他媽的…） | 8 |
| 7 以後 | 三到五個字（關你屁事、血債血還、誰動我的鈴…） | 10 |

- 槍口每格停留的時間從 0.47 秒開始，每過一回合短 0.028 秒，最短 0.17 秒；耐心也掉得越來越快。
- 干擾的注音優先挑長得像的（ㄅㄉ、ㄢㄣ、ㄓㄗ…）。
- 第 3 回合起槍口有時一開始就倒著走，第 6 回合起有時整步都是亂跳。

難度目前只用模擬玩家調過（反應普通的大約撐 10 回合、偏慢的約 6 回合），還沒有真人試玩的數據。模擬玩家不會被假動作騙到，真人應該會更難。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 遊戲本體，單一檔案，沒有建置步驟 |
| `og.png` | 貼到脆、LINE 時的預覽圖（1200×630） |
| `favicon.svg`、`apple-touch-icon.png` | 分頁圖示、加到主畫面的圖示 |

存在瀏覽器裡的資料：`ls.best`（最佳紀錄）、`ls.mute`（靜音）。

句子目前 61 句，有髒話和威脅的話，但沒有放針對特定族群的歧視字眼。

要加句子：在 `index.html` 的 `PHRASES` 裡照「字:注音」的格式加，字和字之間空一格，例如 `'笑:ㄒㄧㄠˋ 死:ㄙˇ'`。四個陣列由短到長。
