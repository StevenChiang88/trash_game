# 被被撐住

一款向 Threads 迷因「卡在遮雨棚上的棉被」致敬的小遊戲。
你是那條被風吹到鄰居鐵皮遮雨棚上的棉被，目標只有一個：今天也不要掉下去。

## 怎麼玩

整個遊戲只有「點」一種操作，沒有按住。

| 操作 | 效果 |
| --- | --- |
| 點螢幕（或空白鍵） | 往牆邊爬一步，也會煞住正在往外滑的被被；每點一下耗 7 點力氣 |
| 點圈圈 | 龍捲風、地震來的時候，把畫面上的圈圈全部點掉 |
| 點鴿子 | 把踩在被被身上的鴿子趕走 |

- **風**：風往外吹（橘色、紅色）會把被被吹得往外滑，一旦開始滑就很難自己停下來，要連點才煞得住、爬得回去。頂著風爬，每一下爬得比較少。往牆邊吹的風（綠色）不用理它。
- **力氣**：停手 0.3 秒後才開始恢復，一直狂點會點到沒力。
- 垂在棚子外面的部分越多，越會被自己的重量拖下去。
- **龍捲風、地震（圈圈事件）**：先有 1.2 秒警報，接著畫面上出現幾個圈，每個圈的外環是剩餘時間。
  - 全部點掉：被被完全不動。
  - 沒點完：依漏掉的比例被推出去。龍捲風一個都沒點到會被推 190（必掉），地震是 120；點掉一半就只推一半。
  - 龍捲風的圈會繞著轉，地震的圈會原地亂抖。
  - 圈圈事件進行中不會吹陣風，點圈圈以外的地方沒有作用。
  - 越後面的天數圈越多、每個圈能用的時間越少。龍捲風第一次在 Day 6（3 個圈），地震第一次在 Day 7（3 個圈）；之後龍捲風每天約一成機率、地震約 14%，兩個不會排在同一天。
- **鴿子**：踩在被被身上時，牠的重量會讓被被慢慢往外滑（就算貼著牆也一樣），而且力氣完全不會恢復。不趕的話牠會待 5 秒。
- 鴿子停超過 1.8 秒就會大便，一隻最多兩坨。每一坨讓力氣上限少 12（最多疊四坨），**只有下雨或颱風才洗得掉**，一個雨天大約洗掉三坨。
- 颱風一次比一次強。
- **新手教學只出現一次**：第一次按「開始曬被」會先跑三步驟教學（連點爬回牆邊 → 把圈圈全部點掉 → 點鴿子趕走），教學裡不會掉下去也不會沒力。學完或按「跳過教學」後會在瀏覽器的 localStorage 記下 `bb.tut=1`，之後直接從 Day 1 開始；標題畫面有「重看教學」可以再跑一次。
- 每 6 秒是一天，撐越多天越好，最佳紀錄存在瀏覽器裡。

## 濕度

力氣條上面那條藍色的是被被的濕度。

- **下雨、颱風**：鐵皮變滑，被被同時吸水，一個雨天就會濕透。雨停後鐵皮很快就乾，被被不會。
- **濕的被被**：變重，垂在外面的部分更會把自己拖下去，每點一下爬得比較少；好處是比較不怕風。
- **出太陽**：白天的太陽會把被被慢慢曬乾（大約兩個晴天），有風也會乾得快一點，晚上幾乎不會乾。
- **完全曬乾**：蓬鬆的被被回力氣比較快。

## 執行

沒有任何建置步驟，直接用瀏覽器打開這個資料夾裡的 `index.html` 就能玩（電腦上會以手機尺寸置中顯示）。
畫面、物理與音效全部寫在這一個檔案裡（Canvas 2D + Web Audio 即時合成），只有字型從 Google Fonts 載入。
