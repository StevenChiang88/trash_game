# 被被撐住

一款向 Threads 迷因「卡在遮雨棚上的棉被」致敬的小遊戲。
你是那條被風吹到鄰居鐵皮遮雨棚上的棉被，目標只有一個：今天也不要掉下去。

## 怎麼玩

| 操作 | 效果 |
| --- | --- |
| 按住螢幕不放（或空白鍵） | 抓緊鐵皮、煞住正在滑的被被，會消耗力氣 |
| 連點螢幕 | 沒風又沒在滑的時候，一下一下往牆邊爬回去 |
| 點鴿子 | 把踩在被被身上的鴿子趕走 |

- **按住是唯一的煞車**：要按住超過 0.14 秒才算抓，比這短的都只是點一下，完全沒有抓的效果。
- **一旦開始往外滑就停不下來**：滑動中的被被鐵皮幾乎拉不住，只有按住不放才會停。滑動中連點既煞不住，也爬不回去。
- **連點只在靜止又沒什麼風的時候有用**：風往外吹得越大爬得越少，風大時完全爬不動。
- **新手教學只出現一次**：第一次按「開始曬被」會先跑三步驟教學（按住撐過陣風 → 連點爬回牆邊 → 點鴿子趕走），教學裡不會掉下去也不會沒力。學完或按「跳過教學」後會在瀏覽器的 localStorage 記下 `bb.tut=1`，之後直接從 Day 1 開始；標題畫面有「重看教學」可以再跑一次。
- 風往外吹（橘色、紅色）才危險；往牆邊吹（綠色）可以放手休息回力氣。
- 垂在棚子外面的部分越多，越會被自己的重量拖下去。
- 鴿子踩在被被身上的時候：牠的重量會讓被被慢慢往外滑（就算貼著牆也一樣），而且力氣完全不會恢復。不趕的話牠會待 5 秒。
- 鴿子停超過 1.8 秒就會大便，一隻最多兩坨。每一坨讓力氣上限少 12（最多疊四坨），**只有下雨或颱風才洗得掉**，一個雨天大約洗掉三坨。
- 地震時抓緊也只有六成效果；颱風一次比一次強。
- **龍捲風**：先有 1.6 秒警報，接著經過 1.6 秒。這段時間只有按住不放擋得住，抓牢了完全不受影響，沒抓住會整條被捲走，連點也沒用。龍捲風期間抓緊比平常省力。第一次出現在 Day 6，Day 10 之後每天約有一成機率。
- 每 6 秒是一天，撐越多天越好，最佳紀錄存在瀏覽器裡。

## 濕度

力氣條上面那條藍色的是被被的濕度。

- **下雨、颱風**：鐵皮變滑，被被同時吸水，一個雨天就會濕透。雨停後鐵皮很快就乾，被被不會。
- **濕的被被**：變重，垂在外面的部分更會把自己拖下去，抓緊更耗力氣，往牆邊爬也爬得少；好處是比較不怕風。
- **出太陽**：白天的太陽會把被被慢慢曬乾（大約兩個晴天），有風也會乾得快一點，晚上幾乎不會乾。
- **完全曬乾**：蓬鬆的被被回力氣比較快。

## 執行

沒有任何建置步驟，直接用瀏覽器打開這個資料夾裡的 `index.html` 就能玩（電腦上會以手機尺寸置中顯示）。
畫面、物理與音效全部寫在這一個檔案裡（Canvas 2D + Web Audio 即時合成），只有字型從 Google Fonts 載入。
