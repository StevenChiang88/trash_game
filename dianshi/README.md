# 絕命電師

Chu克對電過敏，卻得披著太空毯上街拿報紙。三線道跑酷：左右換線、跳、蹲，閃開路上所有帶電的東西，被電到三次就發作，看他能跑多遠。

向《絕命律師》裡那位對電過敏的哥哥致敬的同人小遊戲，非官方、與原作及其製作公司無關。畫面全部是自己畫的卡通造型，路人只取穿著打扮，沒有任何名字。

## 怎麼玩

| 動作 | 手機 | 電腦 |
| --- | --- | --- |
| 換線 | 左右滑 | ← → 或 A D |
| 跳 | 往上滑 | ↑、W 或空白鍵 |
| 蹲 | 往下滑（在空中滑會立刻落地再蹲） | ↓ 或 S |
| 暫停 | 右上角按鈕，離開畫面也會自動暫停 | Esc 或 P |

滑一下就是一個動作，不需要按住。

## 路上的東西

| 東西 | 怎麼過 |
| --- | --- |
| 變電箱、夾娃娃機、充電樁、拿著手機的路人 | 只能換線閃開 |
| 掃地機器人（有的會左右亂跑）、橫跨整條路的延長線 | 跳過去 |
| 跑馬燈招牌、橫跨整條路的燈串 | 蹲下鑽過去 |

每一列一定留一條過得去的路，報紙會排在那條路上：排成弧線表示要跳，貼著地面表示要蹲。

| 撿得到的 | 效果 |
| --- | --- |
| 報紙 | 每撿滿 100 份，Chu克冷靜下來，恢復一格 |
| 太空毯 | 多裹一層，可以擋掉一次電擊 |
| 停電 | 全區停電 6 秒，所有東西都不帶電，可以直接穿過去 |

路人是劇中幾位熟面孔的造型（弟弟、金髮馬尾的律師、金髮合夥人、助理、前妻、修門的、醫生、偵探），還有鄰居、外送員和小孩，經過時會對他喊話。

## 難度

- 速度從每秒 10.5 公尺開始，跑到 2.5 公里加到 25，之後再慢慢加到 32。
- 障礙的間隔越來越短，三條線都要做動作才能過的組合越來越多。
- 第一、二次玩，開頭三列是教學（跳、蹲、換線各一次），畫面上方會提示。
- 天色會隨距離從傍晚入夜再天亮，每 2.4 公里一輪。

難度目前只用模擬玩家調過，還沒有真人試玩的數據。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 遊戲本體，單一檔案，沒有建置步驟 |
| `og.png` | 貼到脆、LINE 時的預覽圖（1200×630） |
| `favicon.svg`、`apple-touch-icon.png` | 分頁圖示、加到主畫面的圖示 |

存在瀏覽器裡的資料：`ds.dist`（最佳紀錄）、`ds.runs`（玩過幾次，用來決定要不要出教學）、`ds.mute`（靜音）。

這款遊戲的第一版是「守門」玩法（客人進門前把帶電的東西丟進信箱），後來整個改成跑酷；舊版留在 git 歷史裡。
