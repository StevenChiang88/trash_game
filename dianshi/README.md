# 絕命電師

守門小遊戲。Chu克對電過敏，家裡不插電、點煤油燈、整個人裹在一件銀色太空毯裡。客人上門時，你要在他們進屋前把身上帶電的東西全部找出來丟進信箱，還要讓他們把靜電放掉。

這是向一部影集致敬的非官方粉絲創作。客人沒有名字，只有造型；畫面全部是自己畫的卡通，沒有使用該影集的劇照、標誌或演員肖像。

## 怎麼玩

畫面是門口。Chu克裹著太空毯、提著煤油燈站在左下角的門邊；客人站在中間，身邊一顆顆圓鈕是他帶的東西；右下角是信箱；右上角門框上有一顆銅色的靜電釋放器。

| 操作 | 效果 |
| --- | --- |
| 點帶電的東西 | 丟進信箱 |
| 點包包 | 打開，裡面藏的東西會跑出來 |
| 點靜電釋放器 | 客人伸手摸一下，放掉一次靜電 |
| 按「請進」（或空白鍵、Enter） | 放客人進門。時間到也會自動進門 |

- **漏掉帶電的東西**：客人一進門 Chu克就會被電到，右上角的閃電亮一格。一次漏三樣以上亮兩格。三格全亮他就發作，遊戲結束。漏掉的東西會標出名字。
- **靜電沒放掉**：客人身上劈啪作響、釋放器外面有藍色圈圈時，代表他帶靜電。沒放掉就進門，一樣算漏掉一樣。後面的客人可能要摸 2～3 下。
- **點到沒電的東西**：客人會不高興，這一位的時間少 1.3 秒。不會讓 Chu克受傷。
- **恢復**：連續 6 位客人都安全進門，閃電會熄掉一格。
- **長得像的**：有電和沒電的常常成對出現，要看清楚。

| 有電 | 長得像的沒電版 |
| --- | --- |
| 智慧手錶 | 機械錶 |
| 遙控鑰匙 | 鑰匙 |
| 電子書 | 筆記本 |
| 手電筒 | 蠟燭 |
| 計算機 | 算盤 |
| 手持電風扇 | 紙扇 |
| 筆電 | 書 |
| 手機 | 皮夾 |
| 電池 | 鉛筆 |
| 行動電源 | 信 |
| 錄音筆 | 鋼筆 |
| 電鑽 | 鐵鎚 |
| 相機 | 望遠鏡 |

另外還有藍牙耳機（有電），以及雨傘、蘋果、小提琴、聽診器、報紙（沒電）。

## 客人

前 8 位照順序登場，之後隨機出現（七成是這 8 位，三成是鄰居、外送員、小孩）。

| 造型 | 習性 |
| --- | --- |
| 穿 polo 衫來送東西的年輕人 | 第 1 位，只帶 2 樣，當作教學 |
| 金髮馬尾、穿套裝的律師 | 很仔細，身上常常一樣帶電的都沒有，考驗你會不會亂點 |
| 金髮、藍色條紋西裝、笑容滿面的合夥人 | 很忙，時間少 12%，帶電的至少三樣，一定有筆電和手機 |
| 油頭、芥末黃西裝、花領帶的弟弟 | 一定帶電池；第 5 位之後會把兩樣帶電的藏進包包 |
| 穿洋裝、拿小提琴的前妻 | 手機一定放在手提包裡 |
| 光頭、繫工具腰帶的修門工人 | 一定帶電鑽和相機，而且藏在工具箱裡 |
| 穿白袍、掛聽診器的醫生 | 會偷藏一樣帶電的在醫生包裡 |
| 風衣、帽子、墨鏡的偵探 | 相機、錄音筆、望遠鏡，帶電的特別多 |

## 難度

- 東西的數量每 3 位客人多 1 樣，最多 8 樣。
- 時間從大約 8 秒逐漸縮到最短 3.4 秒（東西多、有包包、有靜電會多給一點）。
- 第 3 位第一次出現靜電，之後每位有一半機率帶靜電。
- 第 9 位之後，偶爾會來一個身上完全沒電的客人，一般客人也可能帶包包。

## 執行

沒有建置步驟，直接用瀏覽器打開這個資料夾裡的 `index.html` 就能玩（電腦上會以手機尺寸置中顯示）。畫面和音效都寫在這一個檔案裡，只有字型從 Google Fonts 載入。最佳紀錄存在瀏覽器的 localStorage（`ds.best`）。
