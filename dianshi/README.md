# 絕命電師

Chu克對電過敏，卻每天都得披著太空毯上街買報紙。三線道跑酷：左右換線、跳、蹲，閃開路上帶電的東西和迎面來的車，跑到報攤就過一天；後面還有個拿著手機的弟弟在追。

向《絕命律師》裡那位對電過敏的哥哥致敬的同人小遊戲，非官方、與原作及其製作公司無關。畫面全部是自己畫的卡通造型，路人只取穿著打扮，沒有任何名字。

## 怎麼玩

| 動作 | 手機 | 電腦 |
| --- | --- | --- |
| 換線 | 左右滑 | ← → 或 A D |
| 跳 | 往上滑 | ↑、W 或空白鍵 |
| 蹲 | 往下滑（在空中滑會立刻落地再蹲） | ↓ 或 S |
| 暫停 | 右上角按鈕，離開畫面也會自動暫停 | Esc 或 P |

滑一下就是一個動作，不需要按住。

### 在脆、IG 裡面玩

脆、IG、LINE 這類 App 的內建瀏覽器，有時會把「往下滑」「從邊緣往右滑」當成關掉頁面或回上一頁。這是外層 App 的手勢，網頁沒辦法保證擋得住，目前的做法：

- 預設還是用滑的。遊戲畫面上的觸控全部攔在網頁裡（不捲動、不回彈），滑動只要 16px 就會觸發，盡量不讓外層接手。
- 偵測到是內建瀏覽器時，標題畫面會提醒：遇到誤關，點右上角「⋯」改用 Safari 或 Chrome 開啟最順。
- 還是不行的話，標題畫面最下面可以切換成「操作：按鈕」，畫面下方會出現 ← → 蹲 跳四顆按鈕（會記住）。開著按鈕時還是可以用滑的。

## 每天的目標：跑到報攤

- 左上角是第幾天、今天的進度條、離報攤還有幾公尺。
- 第 1 天要跑 250 公尺，之後每天多 100 公尺，最多 1000 公尺。
- 跑到掛著「報攤」布條的地方就拿到今天的報紙，過一天。報攤前後有一小段空路可以喘口氣。
- 每天從白天跑到入夜，過一天就回到早上。
- 一天比一天快（每天起跑速度多 1.7 公尺／秒，最快 31），障礙也排得更密。
- 新東西是一天一天加進來的：第 2 天電動機車和充電樁、第 3 天夾娃娃機和會亂跑的掃地機器人、第 4 天電動公車、第 5 天起三條線都要做動作才過得去的組合。

## 兩種結束方式

- **發作**：右上角三顆紅心，被電到一次少一顆，歸零就發作。
- **被追上**：被電到的時候，後面的弟弟會追上來（畫面邊邊看得到他舉著響個不停的手機）。他還貼在後面的那幾秒內又被電到，就會被追上，直接結束；撐過去他會被甩開。

補心的方法：到報攤時如果受傷而且有 50 枚硬幣，會自動多買一份報紙冷靜下來，補一顆心。

## 路上的東西

| 東西 | 怎麼過 |
| --- | --- |
| 變電箱、夾娃娃機、充電樁、拿著手機的路人 | 只能換線閃開 |
| 迎面衝來的電動機車、電動公車 | 只能換線閃開；車還遠的時候，它那條線上會閃驚嘆號 |
| 掃地機器人（有的會左右亂跑）、橫跨整條路的延長線 | 跳過去 |
| 跑馬燈招牌、橫跨整條路的燈串 | 蹲下鑽過去 |

每一列一定留一條過得去的路，硬幣會排在那條路上：排成弧線表示要跳，貼著地面表示要蹲。

| 撿得到的 | 效果 |
| --- | --- |
| 硬幣 | 買報紙的錢，到報攤時 50 枚換一顆心 |
| 太空毯 | 多裹一層，可以擋掉一次電擊（也不會讓弟弟追近） |
| 停電 | 全區停電 6 秒，所有東西都不帶電，可以直接穿過去 |

路人是劇中幾位熟面孔的造型（弟弟、金髮馬尾的律師、金髮合夥人、助理、前妻、修門的、醫生、偵探），還有鄰居、外送員和小孩，經過時會對他喊話。

第一、二次玩，開頭三列是教學（跳、蹲、換線各一次），畫面上方會提示，這段期間不會被追上。

難度目前只用模擬玩家調過，還沒有真人試玩的數據。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 遊戲本體，單一檔案，沒有建置步驟 |
| `og.png` | 貼到脆、LINE 時的預覽圖（1200×630） |
| `favicon.svg`、`apple-touch-icon.png` | 分頁圖示、加到主畫面的圖示 |

存在瀏覽器裡的資料：`ds.pad`（要不要顯示按鈕）、`ds.day`（最佳紀錄是第幾天）、`ds.dist`（最遠距離）、`ds.runs`（玩過幾次，用來決定要不要出教學）、`ds.mute`（靜音）。

這款遊戲的第一版是「守門」玩法（客人進門前把帶電的東西丟進信箱），後來整個改成跑酷；舊版留在 git 歷史裡。
