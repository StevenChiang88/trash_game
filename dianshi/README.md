# 絕命電師

守門小遊戲。夸克對電過敏，家裡不插電、點煤油燈、身上披著鋁箔毯。客人上門時，你要在他們進屋前把身上帶電的東西全部找出來丟進信箱。

這是向一部影集裡「對電磁波過敏的哥哥」致敬的原創作品：主角、畫面和名稱都是自己做的，沒有使用該影集的角色名稱、肖像或素材。

## 怎麼玩

畫面是門口。夸克裹著銀色太空毯、提著煤油燈站在左下角的門邊；客人站在中間，身邊一顆顆圓鈕是他帶的東西；右下角是信箱。

| 操作 | 效果 |
| --- | --- |
| 點帶電的東西 | 丟進信箱 |
| 點包包 | 打開，裡面藏的東西會跑出來 |
| 按「請進」（或空白鍵、Enter） | 放客人進門。時間到也會自動進門 |

- **漏掉帶電的東西**：客人一進門夸克就會被電到，右上角的閃電亮一格。一次漏三樣以上亮兩格。三格全亮他就發作，遊戲結束。漏掉的東西會標出名字。
- **點到沒電的東西**：客人會不高興，這一位的時間少 1.3 秒。不會讓夸克受傷。
- **恢復**：連續 6 位客人都安全進門，閃電會熄掉一格。
- **長得像的**：有電和沒電的常常成對出現，要看清楚。

| 有電 | 長得像的沒電版 |
| --- | --- |
| 智慧手錶 | 機械錶 |
| 遙控鑰匙 | 鑰匙 |
| 電子書 | 筆記本 |
| 手電筒 | 蠟燭 |
| 計算機 | 算盤 |
| 手持電風扇 | 紙扇 |
| 筆電 | 書 |
| 手機 | 皮夾 |
| 電池 | 鉛筆 |
| 行動電源 | 信 |

另外還有藍牙耳機（有電），以及雨傘、蘋果（沒電）。

## 難度

- 第 1 位客人只有 2 樣東西、10 秒，當作教學。
- 東西的數量每 3 位客人多 1 樣，最多 8 樣。
- 時間從大約 8 秒逐漸縮到最短 3.4 秒（東西越多會多給一點）。
- 第 5 位之後，偶爾會來一個身上完全沒電的客人。
- 第 6 位之後，有些客人會帶包包，要先點開才看得到裡面。
- 第 4 位之後，穿花襯衫的弟弟會出現。他身上至少有兩樣帶電的，而且專門把帶電的藏在包包裡。

## 執行

沒有建置步驟，直接用瀏覽器打開這個資料夾裡的 `index.html` 就能玩（電腦上會以手機尺寸置中顯示）。畫面和音效都寫在這一個檔案裡，只有字型從 Google Fonts 載入。最佳紀錄存在瀏覽器的 localStorage（`ds.best`）。
