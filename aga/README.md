# 阿嘎跟不上我吧

「阿！跟不上我的速度吧，阿嘎！」一路往前跑，跳過機車、鏟過招牌，阿嘎在後面追。等他追到喘的時候回頭嗆他，看你能跑多遠。

角色都是自己畫的卡通造型：跑在前面的是綁紅頭帶、穿白 T 的男生；後面追的「阿嘎」穿綠色運動外套、反戴黃帽子。

## 怎麼玩

| 操作 | 手機 | 鍵盤 |
| --- | --- | --- |
| 跳 | 點一下畫面（手指一放下就跳） | 空白鍵／↑／W |
| 鏟地 | 往下滑（剛跳起來就往下滑，會直接改成鏟地；在空中往下滑，會快點落地、落地馬上鏟） | ↓／S |
| 回頭嗆 | 往左滑，或按右下角的「嗆！」 | ←／A／Z |
| 暫停 | 右上角的暫停鈕 | Esc／P |

他會一直往右跑，越跑越快（每秒 6.5 公尺起，跑到約 1,270 公尺時到頂，每秒 13.5 公尺）。

## 阿嘎

- 一開始在你後面 12 公尺。他平常跑得比你快一點點，一開始每秒多 0.35 公尺，每多跑 650 公尺再多 1 公尺。所以距離會一直縮短。
- **追上你（距離 0.6 公尺以內）就結束。** 他太遠的時候畫面左邊會顯示「◀ 阿嘎 幾公尺」，最多落後 22 公尺。
- **他每隔 5～7.5 秒會追到喘**（越後面隔得越久），頭上出現「呼…呼…」和一個慢慢縮小的圈，喘 1.05 秒；喘的時候他跑得比較慢。
  - 他喘的時候回頭嗆：他氣到停在原地 1.2 秒，距離一下子拉開。
  - 圈縮到最小那一段（最後四成、變紅色）嗆：「完美嗆聲」，他停 1.75 秒。
  - 他沒在喘的時候嗆：他被激怒，1.5 秒內每秒多跑 2.4 公尺。
  - 回頭嗆的那 0.5 秒不能跳、不能鏟；嗆完要等 0.9 秒才能再嗆。
- 連續嗆成功有連擊，分數越加越多。

## 路上的東西

| 東西 | 怎麼過 | 出現在 |
| --- | --- | --- |
| 三角錐、垃圾桶、停著的機車、跑過來的狗 | 跳 | 各段 |
| 布條、招牌、夜市攤位、低垂的樹枝 | 鏟過去（跳起來會撞到） | 各段 |
| 水窪 | 跳過去；踩過去會滑一下 | 各段 |
| 珍奶 | 吃到之後 2.5 秒跑快 35% | 隔一段路一杯，有的要跳起來才拿得到 |

- 撞到東西會踉蹌：1 秒內速度掉到 35% 再慢慢恢復，阿嘎會趁機追近；撞到之後 1.1 秒內不會再被撞。
- 東西之間的距離會隨速度拉開，跑越快間隔越大，不會出現跳不過的組合。

跑過的地方：學校操場（0 公尺起）→ 騎樓街道（300）→ 夜市（700）→ 河濱夜跑（1,100）。

## 分數和封號

- 主要紀錄是**跑了幾公尺**。分數 = 公尺 + 嗆聲（成功 30、完美 60，連續成功每次多 20%，最多 2 倍）+ 珍奶 15。

| 跑了幾公尺 | 封號 |
| --- | --- |
| 0 | 一下就被抓到 |
| 100 | 剛熱身 |
| 300 | 有點快 |
| 700 | 跑給阿嘎追專家 |
| 1,100 | 夜市飛毛腿 |
| 1,500 | 河濱一陣風 |
| 2,000 | 阿嘎永遠追不上的男人 |

## 聲音

- 配樂是程式合成的八小節循環（每分鐘 150 拍）：大鼓、小鼓、踩鈸、低音、主旋律。阿嘎離你不到 4 公尺時，多一層警報聲和心跳。
- 嗆聲那一句用裝置內建的中文語音唸；沒有中文語音的裝置只有字幕。其他音效都是程式合成的。

## 平衡

難度只用模擬的玩家跑過（各 20 次），還沒有真人試玩的數據。模擬的玩家會在差不多對的時候跳或鏟（有時間誤差，偶爾沒反應），等阿嘎喘的時候瞄準圈縮到最小那一段嗆（也有時間誤差），偶爾會忍不住太早嗆：

| 模擬的玩家 | 跑了幾公尺（中位數） | 一次多久 |
| --- | --- | --- |
| 新手（時間誤差約 ±0.09 秒，8% 沒反應） | 430 | 約 1 分鐘 |
| 普通（±0.06 秒，4%） | 950 | 約 1 分 40 秒 |
| 熟手（±0.035 秒，1.5%） | 1,420 | 約 2 分 20 秒 |

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 遊戲本體，單一檔案，沒有建置步驟；畫面用 canvas 畫，音效和配樂用 Web Audio 合成 |
| `og.png` | 貼到脆、LINE 時的預覽圖（1200×630） |
| `favicon.svg`、`apple-touch-icon.png` | 分頁圖示、加到主畫面的圖示 |

存在瀏覽器裡的資料：`ag.best`（最遠跑了幾公尺）、`ag.mute`（靜音）。

要調數值：

- 跑的速度：`V0`、`V_D`、`V_MAX`；阿嘎追多快：`CH0`、`CH_D`；一開始離多遠、最多多遠、多近算追上：`GAP0`、`GAP_MAX`、`CATCH`。
- 跳和鏟：`JUMP_V`、`GRAV`、`SLIDE_T`；撞到：`STUM_T`、`STUM_K`、`INV_T`；珍奶：`TEA_T`、`TEA_K`。
- 嗆聲：`PANT_GAP`（多久喘一次）、`PANT_T`（喘多久）、`PERFECT`（完美的那一段）、`STUN`（被嗆到停多久）、`RAGE_T`、`RAGE_V`（被激怒）、`TAUNT_T`、`TAUNT_CD`。
- 路上的東西：`KIND`；每一段的場景和會出現的東西：`SCENES`；東西之間的距離：`spawn`。
- 封號：`RANKS`；嗆聲的台詞：`TAUNTS`、`AGA_MAD`、`AGA_FIRE`；配樂：`MEL`、`ROOT`、`musicStep`。
